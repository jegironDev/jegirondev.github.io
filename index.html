Uso de TAGS aprendidos en W3Schools

Tema aprendido Ejemplo
Encabezados

<h1> texto... </h1>
<h2> texto... </h2>
<h3> texto... </h3>
<h4> texto... </h4>
<h5> texto... </h5>
<h6> texto... </h6>

Formato de texto negrita, cursiva, resaltado, pequeño, tachado y subrayado
Parrafos

Para insertar un parrafo:
<p> texto... </p>

Para insertar un salto de línea:
<p> texto... </p><br>

Para insertar una línea horizontal después de un párrafo:
<hr>

Para insertar texto pre-formateado, respeta los saltos de línea:
<pre>
 texto...
 texto...
</pre>

Para insertar texto con formato de código:
<code> texto... </code>

Nota: Generalmente se usa junto a <pre>...</pre>:
<pre><code> texto... </code></pre>

Uso de emojis

Los emojis son caracteres del alfabeto UTF-8:
&#128512;
&#9917;
&#128187;

Ejemplo:
😀 ⚽ 💻

Nota: Debe incluirse en el encabezado la etiqueta <meta charset="UTF-8"> para que el navegador reconozca e interprete los emojis.

Enlaces e imagenes

Para crear un enlace:
<a href="https://www.w3schools.com"> Texto de referencia del enlace </a>

Ejemplo:
Enlace a W3Schools

Para insertar una imagen:
<img src="ruta y nombre del archivo" alt="Texto alternativo si la imagen no puede mostrarse" width="ancho" height="alto">

Ejemplo:
Citas

Para insertar una cita larga:
<blockquote> texto... </blockquote>

Para insertar una cita corta dentro de un párrafo, agrega comillas automáticamente.
<p><q> texto... </q></p>

Para indicar el título de una obra (libro, película, canción, videojuego, etc.):
<p> texto... <cite> Titulo de una obra </cite></p>
Informacion de contacto

Para agregar información de contacto, el texto se muestra en cursiva:
<address>
Nombre...
Correo...
Teléfono...
</address>

Tablas 

<table>                       <- Tabla
<tr>                          <- Fila
<th>Encabezado</th>           <- Encabezado de columna
</tr>
<tr>                          <- Fila
<td>Celda</td>                <- Celda
</tr>
</table>
Div y diseño

Para crear un contenedor genérico, para agrupar contenido:
<div>
  Contenido...
</div>

Lista desordenada

Para crear una lista con viñetas:
<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
</ul>

Lista ordenada

Para crear una lista con numeros:
<ol>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
</ol>

Lista de descripciones

Para crear una lista de términos y descripciones:
<dl>
  <dt>Termino</dt>
  <dd>Descripción</dd>
</dl>

Nota: <dt> representa el termino y <dd> su descripción.

Elementos Semanticos

Encabezado de la pagina:
<header>...</header>

Barra de navegacion:
<nav>...</nav>

Sección de contenido:
<section>...</section>

Contenido independiente (articulo):
<article>...</article>

Contenido complementario:
<aside>...</aside>

Pie de pagina:
<footer>...</footer>

Nota: Estas etiquetas se usan para organizar la estructura de la pagina, no cambian la apariencia del contenido.
